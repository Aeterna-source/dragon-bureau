# Bureau of Inner Dragons

First local playable prototype for the Dragon Bureau concept.

This version is intentionally static and uses a local mock of the future GPT/Image Gen flow:

- full-screen scene backgrounds;
- four theatrical NPC departments;
- scene music;
- free-form answers;
- simple local clan assignment;
- generated dragon name and draft Image Gen prompt.

Later API-backed version should replace `app.js` mock dialogue/result logic with server endpoints for GPT-5.5 and Image Gen while keeping the same scene data structure.
